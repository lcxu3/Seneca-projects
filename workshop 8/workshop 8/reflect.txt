In this workshop, I learned about raw and smart pointers.
Raw pointers are pointers that hold an address to that memory location.
Smart pointers are pointers that can manage the memory of the resource object to which it is pointing.

These two functions are responsible for merging two lists of descriptions and prices into a list of products.
For mergeRaw() and mergeSmart() I used the unique_made function to create these smart and raw pointers.
what the unique_made function does is it will create a new unique pointer to manage the new pointer object.
